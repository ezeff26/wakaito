ワカイトキー運営者（以下「当方」）は、ワカイトキーのソフトウェアおよびウェブサイト（wakaito.com）における個人情報の取扱いについて、以下のとおり定めます。

1. ソフトウェアについて

  • ワカイトキーは、お使いのPCの中だけで動作します。インターネットへの通信は一切行いません。
  • 入力したキーや文字は、日本語入力に受け渡すためだけに使われ、保存や外部への送信は行いません。
  • 不具合のお問い合わせの際、当方からお願いした場合に限り、動作の記録ファイルをPC内に作成していただくことがあります。この記録を当方に送るかどうかは、お客様ご自身の判断によります。

2. ウェブサイトについて

  • 本サイトは GitHub Pages（GitHub, Inc.）で公開しています。アクセス時の情報（IPアドレス等）は GitHub が記録することがあります。詳しくは GitHub のプライバシーステートメントをご覧ください。

  • 当方は、アクセス解析ツールや広告用の Cookie を使用していません。
  • タイピング練習の進み具合などは、お使いのブラウザの中（localStorage）にのみ保存され、当方には送信されません。
  • 特典付きの募集の残り人数を表示するために、ページを開いた際に Google（Google LLC）のサービスへ接続します。このとき、お使いのブラウザから Google に IPアドレス等が送信されます。

利用目的
